# Portfolio · Benito Gallardo Peral

Portfolio personal hecho con HTML, CSS y JavaScript (sin frameworks).

Estructura inspirada en la web de Adrià Solà Pastor: hero con etiqueta y palabra protagonista,
bloque de contacto destacado, áreas de trabajo, cuadrícula de tecnologías, proyectos en bloques
alternos, "Sobre mí" con checks, llamada a la acción final y footer.

- Modo claro / oscuro (respeta el del sistema y recuerda tu elección)
- Responsive y accesible (menú móvil, foco visible, reduce-motion)
- Para verlo, abre `index.html` en el navegador.
